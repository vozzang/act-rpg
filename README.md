# ACT RPG

최대 4명이 함께 즐기는 웹 기반 **3D 협동 액션 RPG**입니다. 워크래프트3처럼 비스듬히 내려다보는 시점으로 플레이합니다.
설치 없이 브라우저에서 바로 플레이하고, **저장 기능이 없습니다**. 매 판 1레벨 맨몸으로 시작해서 한 번에 최종 보스까지 깨야 합니다.

**▶ 플레이:** https://vozzang.github.io/act-rpg/

## 게임 방법

1. 닉네임을 입력하고 **방 만들기**를 누르면 5자리 방 코드가 나옵니다.
   **초대 링크 복사**로 친구에게 링크를 보내면, 친구는 코드가 채워진 상태로 바로 참가할 수 있습니다.
   혼자 하려면 **혼자 하기**를 누르세요.
2. 각자 직업을 고릅니다. 한 방에서 같은 직업은 한 명만 고를 수 있습니다.
3. 방장이 **게임 시작**을 누르면 출발합니다. 맵은 개발자가 만든 하나의 맵을 모두가 똑같이 플레이합니다.
4. 10개 구역을 지나 오른쪽 끝 보스 방의 **흑룡**을 쓰러뜨리면 승리합니다.

### 효과음

공격·명중·스킬·폭발·몬스터 쓰러짐·레벨업·돈 줍기·구매·음식·문 열림·쓰러짐·부활·승리·패배 등에 효과음이 납니다.
내 캐릭터에서 먼 곳의 소리는 작게 들리고, 아주 멀면 나지 않습니다. 로비의 **효과음 크기**로 조절합니다(0이면 끔, 이 브라우저에 기억).
소리는 `public/sfx/`(모두 CC0), 어떤 상황에 어떤 소리를 낼지는 `src/render/sfxEvents.ts`에서 고칩니다.

### 스토리

처음 시작할 때 **인트로**, 각 구역에 처음 들어설 때 그 구역 이야기, 흑룡의 둥지에 들어설 때, 승리하면 **엔딩**이 화면 아래 대화창으로 나옵니다.

- 로비의 **스토리 건너뛰기**를 체크하면 스토리가 나오지 않습니다(이 브라우저에 기억, 플레이어마다 따로).
- 대화창: **클릭·Enter·게임패드 A**로 다음(글자가 나오는 중이면 한 번에 다 보기), **건너뛰기 버튼·Esc·게임패드 B**로 그 장면 건너뛰기.
- **혼자 할 때는 스토리를 보는 동안 게임이 멈춥니다.** 여럿이 할 때는 멈추지 않고(이동은 되고 공격·스킬만 막힘), 각자 자기 화면에서 봅니다.
- 대본은 `src/game/story.ts`에서 고칩니다.

### 협동 규칙

- **경험치는 공유됩니다.** 적을 처치하면 살아 있는 파티원 모두가 같은 경험치를 받습니다.
- **카메라는 각자 따로 움직입니다.** 미니맵, 전체 지도(Tab), 화면 가장자리 화살표로 동료 위치를 확인하세요.
- **쓰러진 동료 곁에 2초간 서 있으면 부활**시킬 수 있습니다. 마법사의 치유의 빛으로도 바로 일으킬 수 있습니다.
- **새 구역에 들어서면** 쓰러진 동료는 맨 앞 동료 곁에서 부활하고, 모두의 HP가 25%, MP가 50% 회복됩니다.
- **모두 쓰러지면 전멸**입니다. 처음부터 다시 시작해야 합니다.
- 참가 인원이 많을수록 적 체력이 늘어납니다(1명 늘 때마다 +70%).

## 조작

키보드·마우스, 게임패드, 휴대폰·태블릿 터치 모두 됩니다. 마지막으로 만진 장치에 맞춰 화면의 버튼 안내가 자동으로 바뀝니다.

### 키보드 + 마우스

| 동작 | 키 |
|---|---|
| 이동 | WASD 또는 방향키 (방향키로 움직이면 이동 방향으로 공격) |
| 조준 | 마우스 커서 방향 |
| 기본 공격 (누르고 있으면 연속) | 좌클릭 · Z |
| 스킬 1~4 | 숫자키 1~4 (우클릭·X·Space = 1번) |
| 아이템 줍기 · 상점 열기 | E |
| 상자 칸 사용 (음식 먹기 · 장비를 가방에) | 5·6·7·8·9·0 또는 칸 클릭 |
| 음식 먹기 (HP / MP) | Q / R |
| 능력치 배분 | Shift+1~4 또는 화면 버튼 클릭 |
| 캐릭터 메뉴 | I |
| 전체 지도 | Tab(누르고 있기) · M(켜고 끄기) |

### 게임패드 (Xbox 이름, 괄호는 PlayStation)

| 버튼 | 동작 |
|---|---|
| 왼쪽 스틱 | 이동 |
| 오른쪽 스틱 | 조준. **안 쓰면 자동 조준** (이동 방향 앞쪽의 가장 가까운 적) |
| **X (□)** 누르고 있기 | 기본 공격 |
| **A (✕) · B (○) · Y (△)** | 스킬 1 · 2 · 3 |
| **RT (R2)** | 스킬 4 (최종 스킬) |
| **LB (L1) / RB (R1)** | HP 음식 / MP 음식 먹기 |
| **LT (L2)** | 줍기 · 상점 열기 |
| **Menu (Options)** | 캐릭터 메뉴: 능력치 배분, 아이템 상자 (방향패드로 고르고 A 실행, B 닫기) |
| **View (Share)** | 전체 지도 |

- 상점 창과 캐릭터 메뉴는 방향패드로 고르고 **A**로 실행, **B**로 닫습니다.
- 메뉴가 열려 있어도 게임은 멈추지 않습니다(온라인). 대신 **왼쪽 스틱 이동과 음식 먹기는 그대로** 되고, 공격·스킬만 막힙니다.

### 터치 (휴대폰 · 태블릿)

휴대폰은 **가로로** 들고 합니다. 세로로 들면 돌려 달라는 안내가 나옵니다. 게임을 시작하면 전체 화면으로 바뀝니다(참가자는 대기실의 **전체 화면** 버튼을 미리 누르세요).

| 화면 | 동작 |
|---|---|
| 왼쪽 절반 아무 곳이나 누른 채 끌기 | 이동 (누른 자리에 조이스틱이 생김) |
| 오른쪽 아래 큰 **공격** 버튼 (누르고 있기) | 기본 공격. 조준은 **자동** (게임패드와 같음) |
| 공격 버튼 둘레 작은 버튼 4개 | 스킬 1~4 (못 쓰는 동안은 어둡게, 🔒는 아직 못 배운 스킬) |
| **줍기** | 아이템 줍기 · 상점 열고 닫기 |
| **HP / MP** | 음식 먹기 |
| **메뉴** | 캐릭터 메뉴: 줄을 눌러 능력치 배분 · 음식 먹기 · 장비를 가방 ↔ 상자로 옮기기, [버리기] 버튼 |
| **지도** | 전체 지도 켜고 끄기 (터치에서는 미니맵을 숨겨 버튼 자리를 만든다) |
| 아이템 상자 칸 · 상점 줄 | 눌러서 사용 · 구매 |

- 여러 손가락을 동시에 쓸 수 있습니다 (이동하면서 공격·스킬).
- 휴대폰에서는 3D 화질을 조금 낮춰(안티에일리어싱 끔, 그림자 해상도 절반) 프레임을 지킵니다.

| 직업 | 종족 | 주 능력치 | 기본 공격 | 특징 |
|---|---|---|---|---|
| **검사** | 휴먼 | 힘 | 빠른 근접 베기 | 균형 잡힌 능력치. 돌진으로 파고들어 싸운다. |
| **수호자** | 드워프 | 체력 (공격은 힘) | 느리지만 강한 도끼질, 강한 넉백 | HP와 방어가 높다. **적이 우선적으로 노린다.** |

## 능력치

능력치는 **힘·민첩·지능·체력** 4가지입니다.

| 능력치 | 효과 |
|---|---|
| **힘** | 검사·수호자의 공격력, 방어 |
| **민첩** | 궁수의 공격력, 치명타 확률, 공격 속도, **회피 확률** (1당 0.25%, 최대 25%. 피하면 "회피!"가 뜨고 피해를 받지 않는다) |
| **지능** | 마법사의 공격력, 최대 MP, MP 회복 속도, 스킬 재사용 가속, 회복 스킬 효과 |
| **체력** | 최대 HP, 방어 (수호자의 주 능력치: 힘에 주면 공격형, 체력에 주면 탱커형) |

- 공격력은 **직업의 주 능력치**에서 나옵니다. 다른 능력치도 각자 쓸모가 있습니다. 예를 들어 마법사가 체력을 올리면 덜 죽고, 검사가 민첩을 올리면 더 빨리 벱니다.
- **레벨업할 때마다** 직업에 맞게 능력치가 자동으로 오르고, **포인트 3을 받아 원하는 곳에 직접 배분**할 수 있습니다.
- 레벨업하면 HP와 MP가 30%씩 회복됩니다.
- 화면 왼쪽 아래 정보창에서 현재 능력치(주 능력치는 ★)와 공격·방어·치명·공격 속도·스킬 가속을 볼 수 있습니다.

## MP와 스킬

### MP

- 모든 스킬은 MP를 씁니다. **위력이 큰 스킬일수록 MP가 많이 듭니다.**
- MP는 시간이 지나면 차오르고, 지능이 높을수록 최대치와 회복 속도가 늘어납니다.
- 레벨업할 때(30%), 새 구역에 들어갈 때(50%), MP 회복 음식을 먹을 때(50%) 회복됩니다.

### 스킬

직업마다 스킬이 4개입니다. 1레벨에는 하나만 쓸 수 있고, **Lv 4 · 7에 하나씩, Lv 10에 최종 스킬**을 배웁니다.
화면 아래 가운데 스킬 바에서 재사용 대기시간과 필요 MP를 볼 수 있고, 마우스를 올리면 설명이 나옵니다.

검사·수호자가 근접 공격을 하면 공중에 칼자국이 그어집니다. 스킬마다 3D 효과가 있습니다. 냉기 파동은 바닥이 얼고 얼음 가시가 솟으며(맞은 적은 푸르게 얼고 발밑에 얼음), 화염구·메테오는 불꽃 꼬리를 끌고 날아가 폭발한 자리에 그을음을 남기고,
메테오·화살비는 떨어질 곳에 표적 원이 먼저 뜹니다. 대지 강타는 땅이 갈라지며 돌이 튀고(기절한 적 머리 위에 별), 도발·산의 수호를 받은 동안은 금빛 보호막,
전투 함성을 받은 동안은 발밑에 붉은 마법진이 보입니다. 효과는 `src/render/SkillFx.ts`에서 고칩니다.

## 장비와 아이템 상자

- 화면 아래 스킬 바 밑에 **아이템 상자 6칸**이 있습니다. 장비 하나, 또는 같은 종류 음식 한 묶음이 한 칸을 차지합니다.
- **상자에 든 장비는 종류와 상관없이 모두 능력치에 더해집니다.** 무기를 두 개 들면 두 개 다 적용됩니다.
  칸이 6개뿐이라 장비를 더 들지, 회복 음식을 더 들지 골라야 합니다.
- 적이 떨어뜨린 장비 위에 서서 **E**를 누르면 빈 칸에 들어갑니다. 상자가 가득 차 있으면 **가방**에 들어가고, 둘 다 차 있으면 주울 수 없습니다.
- 떨어진 장비 보물상자는 **등급 색**으로 보입니다: 일반은 나무색, 희귀는 파랑, 영웅은 보라 + 빛기둥, 전설은 금색 + 높은 빛기둥 (`World3D.ts`의 `CHEST_LOOK`).
- **상자 칸을 클릭하거나 단축키 5·6·7·8·9·0**(1~6번째 칸)을 누르면 음식은 하나 먹고, 장비는 가방에 넣습니다(능력치에서 빠짐). 마우스를 올리면 설명이 나옵니다.
  상점 창이 열려 있을 때는 숫자키가 구매에 쓰입니다.
- 장비 칸은 등급 색으로, 음식 칸은 HP 빨강·MP 파랑과 개수(×3)로 표시됩니다.

모든 장비는 **아이템 목록**(`src/game/data/items.ts`, 120개)에 이름·종류·등급·수치가 정해져 있습니다. 수치를 바꾸려면 그 표의 숫자를 고치면 됩니다.

- 장비는 **5단계**로 나뉩니다: 1·2구역 **낡은** → 3·4구역 **강철** → 5·6구역 **미스릴** → 7·8구역 **용비늘** → 9·10구역 **마왕의**. 깊은 단계일수록 수치가 높습니다.
- 몬스터는 가끔(종류별 확률 × `ITEM_DROP_MULT` 0.6) 그 구역 단계의 '드랍' 장비 중에서 등급(일반 61% · 희귀 28% · 영웅 10% · 전설 약 0.5%)을 굴려 떨어뜨립니다.
  중간보스·문지기는 장비를 반드시 떨어뜨리고 좋은 등급이 잘 나옵니다(희귀 47% · 영웅 21% · 전설 2%). 한 판에 전설은 평균 1~2개 정도입니다.
- 상점은 그 지점 단계의 정해진 장비를 팔고, 대장간 조합법은 정해진 결과 장비(단계마다 Ⅰ~Ⅴ)를 만듭니다.

| 등급 | 단계마다 있는 장비 | 얻는 곳 |
|---|---|---|
| 일반 | 검(공격·힘), 활(공격·민첩), 완드(공격·지능), 가죽 갑옷(방어·민첩) | 드랍 |
| 희귀 | 대검(공격·힘), 장궁(공격·민첩), 지팡이(공격·지능), 갑옷(방어·체력), 반지(치명·공격), 부적(최대 HP·체력) | 드랍 · 상점 |
| 희귀 | 로브(방어·지능) | 드랍 |
| 영웅 | 판금 갑옷(방어·체력·힘) | 드랍 · 상점 |
| 영웅 | 목걸이(치명·힘·민첩·지능) | 드랍 |
| 전설 | 단계마다 하나: 고블린 왕의 송곳니 · 서리 송곳니 · 화염 군주의 지팡이 · 사막왕의 인장 · 마왕의 검 | 드랍 |
| 전설 | 조합법 결과 10종 × 5단계 (거인의 대검 Ⅰ~Ⅴ 등) | 대장간 |

| 등급 | 색 |
|---|---|
| 일반 · 희귀 · 영웅 · 전설 | 흰색 · 파랑 · 보라 · 주황 |

- 적은 가끔 **회복 음식**도 떨어뜨립니다. 닿으면 주워서, 필요하면 바로 먹고 가득 차 있으면 아이템 상자에 넣습니다.
  - **빨간 빛** 위의 햄·사과: HP 35% 회복 — 상자에서 꺼내 먹기 **Q**
  - **파란 빛** 위의 포도·포도주: MP 50% 회복 — 상자에서 꺼내 먹기 **R**
  - HP 음식, MP 음식은 **각각 최대 5개**까지 들 수 있습니다(각각 상자 한 칸).
- 처음에는 상자에 HP·MP 음식이 하나씩 들어 있습니다.

### 가방

- 장비만 넣는 **가방 6칸**이 따로 있습니다. **가방의 장비는 능력치에 더해지지 않고** 보관만 됩니다(대장간 재료로 모아 두기 좋다).
- **캐릭터 메뉴(I · 게임패드 Menu · 터치 메뉴 버튼)**에 능력치 · 아이템 상자(착용 중) · 가방 세 칸이 있습니다.
  - 상자의 장비를 실행하면 가방으로, 가방의 장비를 실행하면 상자로(착용) 옮깁니다.
  - 장비 **버리기**: 오른쪽 클릭 · Delete · 게임패드 X · [버리기] 버튼. 발밑에 떨어집니다.

### 대장간 (조합)

**짝수 구역(2·4·6·8·10) 입구**의 상점들 오른쪽에 **대장간**(모루와 화로, 지도에 주황 점)이 있습니다. 대장장이 곁에서 **E**로 엽니다.

- 아이템 상자·가방의 장비 **2~3개**를 고르고 두 버튼 중 하나를 누릅니다. 값은 대장간 구역 × 15 G이고, 재료는 사라집니다.
  - **조합하기**: 고른 재료가 **조합법**에 맞으면 정해진 **고유 전설 장비**가 나옵니다(재료와 대장간 중 가장 깊은 단계의 Ⅰ~Ⅴ). 맞지 않으면 만들어지지 않습니다.
  - **랜덤 조합하기**: 무작위 장비가 나옵니다. 재료 중 가장 좋은 등급에서 시작해, 재료가 3개면 55%(2개면 25%), 모두 같은 등급이면 15% 더 높은 확률로 한 단계 위 등급이 됩니다.
- 게임패드: 방향패드로 고르고 A 선택, **X 조합하기**, **Y 랜덤 조합하기**, B 닫기.

| 재료 | 결과 |
|---|---|
| 대검 + 대검 | 거인의 대검 (공격·힘·치명) |
| 장궁 + 장궁 | 바람의 장궁 (공격·민첩·치명) |
| 지팡이 + 지팡이 | 현자의 지팡이 (공격·지능·최대 HP) |
| 대검 + 장궁 + 지팡이 | 삼위일체의 검 (공격·힘·민첩·지능) |
| 갑옷 + 판금 갑옷 | 수호자의 판금 (방어·체력·힘) |
| 부적 + 부적 | 생명의 부적 (최대 HP·체력) |
| 반지 + 반지 | 치명의 반지 (치명·공격) |
| 반지 + 부적 | 용사의 목걸이 (공격·방어·치명·최대 HP) |
| 아무 무기 ×3 | 무쇠 대장장이의 망치 (공격·힘·체력) |
| 아무 방어구 ×3 | 철벽의 갑주 (방어·체력·최대 HP) |

대검·장궁·지팡이·반지·갑옷·판금 갑옷·부적은 공격·방어 상점에서 팝니다. 조합법은 `src/game/data/forge.ts`의 `RECIPES`에서 바꿉니다.

## 돈과 상점

- 몬스터를 쓰러뜨리면 **항상 금화**가 떨어집니다. 깊은 구역의 적, 정예 오크일수록 많이 줍니다.
- 금화는 가까이 가면 저절로 끌려옵니다. **누가 줍든 파티 전원이 같은 만큼 받습니다**(경험치처럼).
- **출발 지점과 2~10구역 입구**마다 상점 가판대 **3개**가 나란히 있습니다. 지도에는 종류별 색 점으로 표시됩니다.
- 상인 곁에서 **E**를 누르면 상점 창이 열립니다. **숫자키** 또는 클릭으로 사고, E·Esc를 누르거나 멀어지면 닫힙니다.
- **판매 목록은 고정**입니다. 같은 지점의 같은 상점은 매 판 같은 물건을 같은 값에 팝니다(뒤 지점일수록 좋은 장비).
- 장비는 **플레이어마다 하나씩** 살 수 있습니다. 내가 산 장비는 내 창에만 "구매함"으로 보이고, 동료는 따로 살 수 있습니다.

| 상점 | 천막 | 판매 |
|---|---|---|
| **회복 상점** | 초록 | HP 회복 음식, MP 회복 음식 (각 20 G, 최대 5개씩) |
| **공격 상점** | 빨강 | 그 지점 단계의 대검 · 장궁 · 지팡이 (희귀, 직업 주 능력치에 맞춰 고르기), 반지 (희귀) |
| **방어 상점** | 나무 | 그 지점 단계의 갑옷 (희귀), 판금 갑옷 (영웅), 부적 (희귀) |

- 1·2구역 지점은 낡은 장비, 3·4구역은 강철 … 9·10구역은 마왕의 장비를 팝니다 (아이템 목록 `items.ts`의 'shop' 장비).
- 장비 값: 희귀 55 · 영웅 110 G에서 단계가 오를 때마다 비싸집니다(같은 단계 장비는 어느 지점에서 사든 같은 값).
- 판매 목록은 `src/game/data/shop.ts`의 `SHOP_ITEMS`, 가판대 위치·종류는 맵 파일(맵 편집기의 상점 도구: 누를 때마다 회복 → 공격 → 방어 → 대장간)에서 바꿉니다.
- 산 물건은 아이템 상자에 들어갑니다(상자가 차 있으면 가방). 둘 다 차 있으면 살 수 없습니다.

| 9 망령의 묘지 | 망령 기사 | 묘지 술사 (화염탄 3발) |

- 같은 구역의 일반 몬스터보다 훨씬 강하고, **뒤 구역일수록 기본 능력치 자체가 높아지고 구역 보정까지 더해져** 점점 강해집니다.
- 모습은 Quaternius 캐릭터(엘프 궁수, 바이킹, 황금 기사 등)이고 싸우는 방식은 저격수는 원거리, 광전사·기사단장은 내려치기입니다. 모델은 `World3D.ts`의 `ELITE_LOOKS`에서 이름으로 고릅니다.
- 넉백을 거의 받지 않고, 기절 시간도 절반입니다.
- 처치하면 경험치 6배, 돈 8배를 주고, **좋은 등급 장비 하나와 회복 음식을 반드시** 떨어뜨립니다.
- 능력치는 `src/game/data/enemies.ts`의 `ELITES`(중간보스별 HP·공격·방어)와 `ELITE`(보상 배율 등)에서 조정합니다.

### 문과 문지기

구역 출구(다음 구역 입구, 10구역은 흑룡의 둥지 입구)마다 양쪽에 망루가 선 **철문**이 있습니다.
문 바로 앞을 지키는 **문지기**를 쓰러뜨려야 철문이 땅속으로 내려가며 열리고, 그때부터 다음 구역으로 갈 수 있습니다.
닫힌 문에 다가가면 "문이 잠겨 있다" 안내가 나오고, 지도에는 닫힌 문이 **빨간 막대**로 표시됩니다.
다음 구역의 상점은 문 바로 너머에 있어서, 문지기를 쓰러뜨리고 받은 돈으로 정비할 수 있습니다.

| 구역 출구 | 문지기 |
|---|---|
| 1 초록 숲 → 2구역 | 숲의 문지기 (고블린) |
| 2 고블린 협곡 → 3구역 | 협곡의 문지기 (사막 닌자, 원거리 화살 3발 부채꼴) |
| 3 얼어붙은 설원 → 4구역 | 설원의 문지기 (바이킹, 내려치기) |
| 4 오크 요새 → 5구역 | 요새의 문지기 (기사, 내려치기) |
| 5 불타는 화산 → 6구역 | 화산의 문지기 (황금 기사, 내려치기) |
| 6 독기의 늪 → 7구역 | 늪의 문지기 (망자) |
| 7 사막 유적 → 8구역 | 사막의 문지기 (약탈자, 내려치기) |
| 8 수정 동굴 → 9구역 | 수정의 문지기 (흑기사, 내려치기) |
| 9 망령의 묘지 → 10구역 | 묘지의 문지기 (흑기사, 내려치기) |
| 10 마왕성 → 흑룡의 둥지 | 흑룡의 문지기 (어두운 황금 기사, 내려치기) |

- 문지기는 중간보스의 한 종류라 같은 규칙(금빛 고리, 넉백·기절 저항, 보상 6배·8배, 좋은 장비 확정)을 따르고, 같은 구역의 중간보스보다 한 단계 강합니다.
- 능력치는 `src/game/data/enemies.ts`의 `GATE_KEEPERS`에서 조정합니다. 문 위치는 맵 파일이 정하고(`gates`), 열린 문은 스냅샷의 `gates`로 참가자에게 전해집니다.

## 개발

### 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 를 정적 호스팅에 올리면 된다
npm run typecheck  # 타입 검사
```

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 빌드해서 GitHub Pages에 자동 배포합니다.

**개발 서버 전용 바로 시작:** `http://localhost:5173/?autostart=elf&seed=1` 처럼 열면 로비를 건너뛰고 혼자 바로 시작합니다.
직업은 `swordsman`, `dwarf`, `elf`, `gnome` 중 하나입니다. 이때 브라우저 콘솔에서 `sim`으로 게임 상태를 살펴보고 바꿀 수 있습니다(예: `sim.players[0].hp = 9999`). 배포된 사이트에는 적용되지 않습니다.

### 정보 페이지 (직업 능력치 · 몬스터 도감 · 아이템 도감)

로비 아래 "📖 직업 능력치 · 몬스터 도감 · 아이템 도감" 링크로 엽니다. 배포된 사이트에도 들어갑니다.

- **classes.html — 직업 능력치**: 직업별로 레벨마다 능력치(힘·민첩·지능·체력), 최대 HP·MP, 공격, 방어, 치명, 회피, 공속, 스킬가속, MP 회복, 누적 경험치를 표로 봅니다. 레벨업 포인트를 어디에 쓸지(주 능력치 / 공격 능력치 / 체력 / 고르게 / 안 씀)와 최고 레벨을 고를 수 있고, 스킬을 배우는 레벨은 강조됩니다.
- **monsters.html — 몬스터 도감**: 일반 몬스터의 행동, 기본 수치, 고른 구역·파티 인원에서의 실제 HP·공격·방어, 경험치·돈·장비 드롭 확률, 나오는 구역(구역별 마릿수)을 봅니다. 중간보스·문지기와 흑룡도 따로 정리돼 있습니다.
- **items.html — 아이템 도감**: 장비 120개의 등급, 종류, 단계(나오는 구역), 수치(공격·방어·최대 HP·치명·능력치)와 얻는 곳을 봅니다. 얻는 곳에는 몬스터 드랍 확률, 중간보스·문지기 드랍 확률, 상점 이름과 값, 대장간 조합법 재료가 나옵니다. 단계·종류·등급·얻는 곳·능력치·이름으로 거를 수 있고, 등급별 확률, 조합법별 단계 수치, 랜덤 조합 규칙도 정리돼 있습니다.
- 수치는 게임 코드(`src/game/data/`)와 맵(`maps/world.json`)에서 바로 계산하므로, 밸런스나 맵을 고치면 페이지도 함께 바뀝니다.

### 맵 편집기

게임 맵은 `src/game/maps/world.json` 하나이고, 모든 플레이어가 이 맵을 플레이합니다. 처음 맵은 자동 생성기(시드 1)로 만들었습니다.
`npm run dev`로 띄운 뒤 **http://localhost:5173/editor.html** (로비의 "🛠 맵 편집기" 링크)에서 고칩니다. 개발 서버 전용이라 배포된 사이트에는 없습니다.

| 도구 | 단축키 | 하는 일 |
|---|---|---|
| 바닥(풀) · 길 · 돌바닥 | 1 · 2 · 3 | 걸을 수 있는 칸으로 칠한다 (바닥 무늬만 다름) |
| 나무 · 바위 | 4 · 5 | 벽으로 칠한다. 붓 크기 `[` `]` |
| 선택·이동 | V | 물건을 끌어 옮기고 Delete로 지운다 |
| 물건 지우기 | X | 누르거나 끌면서 지운다 (어느 도구에서든 오른쪽 클릭도 지우기) |
| 슬라임 · 고블린 · 해골 궁수 · 오크 | Q · W · E · R | 몬스터를 놓는다 |
| 구역별 몬스터 (퍼그 졸개 ~ 화염 술사) | 없음 | 몬스터를 놓는다 (지도에는 소문자로 표시, 마우스를 올리면 아래 상태 줄에 이름) |
| 중간보스 1 · 2 | A · S | 놓은 구역의 첫째·둘째 중간보스 (`ELITES`) |
| 문지기 | D | 놓은 구역의 출구 문지기 (`GATE_KEEPERS`). 여럿이면 모두 쓰러뜨려야 문이 열린다 |
| 문 | G | 세로 통로를 누르면 그 통로를 막는 문이 생긴다 (다시 누르면 없앰) |
| 상점 · 출발점 · 흑룡 | F · Z · B | 놓거나 옮긴다 |
| 장식 | H (+ 목록에서 고르기) | 나무·단풍나무·통나무·바위 · 텐트·모닥불·침낭·과녁·표지판 · 통·상자·수레·작업대·가로등 · 울타리·목책·돌담·기둥·석상 · 눈사람·얼음 결정 등 35가지. 빈 바닥을 누르면 놓고, 같은 칸을 다시 누르면 90도 회전. '통과' 표시가 없는 장식은 길을 막는다 |

- **휠·트랙패드** 화면 이동(Shift+휠은 가로, 방향키도 됨), **Ctrl(⌘)+휠·트랙패드 집기·+/-** 확대·축소, 선택 도구로 **빈 곳을 끌기**(또는 Space+끌기·가운데 버튼)도 화면 이동. **Ctrl+Z / Ctrl+Shift+Z** 되돌리기·다시 하기.
- **3D로 보기 (Tab)**: 편집 중인 맵(저장 전 포함)을 게임과 같은 3D 화면으로 둘러봅니다. 2D에서 **더블클릭**하면 그 자리를 봅니다. 몬스터는 놓인 자리에 서 있고 문은 닫혀 있습니다.
  끌기·휠·WASD(방향키)로 이동, Shift를 누르면 빠르게, Ctrl+휠·Q/E로 확대·축소, Tab·Esc로 2D로 돌아가면 보던 자리가 2D 화면 가운데에 옵니다.
- **저장(Ctrl+S)**: `world.json`을 덮어씁니다. 그다음 커밋·푸시하면 배포된 게임에 반영됩니다.
- **테스트 플레이**: 저장하지 않은 지금 맵으로 새 탭에서 바로 혼자 플레이합니다(`?draft=1`).
- 편집 중인 내용은 브라우저에 초안으로 계속 저장되어, 탭을 닫았다 열어도 "이어서 할까요?"로 돌아올 수 있습니다.
  단 그 사이에 저장된 맵이 바뀌었으면(다른 곳에서 저장했거나 코드로 다시 만든 경우) 예전 초안으로 덮어쓰지 않도록 묻지 않고 저장된 맵을 엽니다.
- **검사**: 출발점에서 흑룡까지 길이 이어지는지, 구역마다 출구 문 1개·문지기가 있는지, 막힌 칸에 놓인 몬스터가 없는지 등을 계속 확인해 왼쪽에 보여줍니다.
- **자동 생성**: 시드를 넣어 자동 생성 맵으로 새로 시작할 수 있습니다. 내려받기·불러오기로 맵 파일을 따로 보관할 수도 있습니다.
- 구역 경계와 맵 크기는 지금은 바꿀 수 없습니다. 나무·바위·눈 장식 모양은 칸 위치에 따라 자동으로 고릅니다(3구역은 설원 모델).

### 기술 스택

- **Three.js**: 3D 월드 렌더링 (지형, 캐릭터 모델과 애니메이션, 조명·그림자)
- **Phaser 3**: HUD, 글자, 입력 (3D 화면 위에 투명하게 겹친 2D 화면)
- **TypeScript + Vite**: 개발 환경과 빌드
- **PeerJS (WebRTC)**: 브라우저끼리 P2P 통신. 별도 게임 서버 없음

```
  session.ts       로비와 게임 화면이 주고받는 정보
```

### 온라인 구조 (호스트 권한 방식)

```
참가자 브라우저 ── 입력(이동·조준·공격·스킬) ──▶ 방장 브라우저 (Sim 실행)
참가자 브라우저 ◀── 스냅샷(초당 20회) ──────── 방장 브라우저
```

- 방장 브라우저가 게임을 초당 60회 계산하고, 초당 20회 상태를 참가자에게 보냅니다.
- 참가자는 입력만 보내고, 받은 상태를 부드럽게 이어서(보간) 그립니다.
- 스냅샷에는 플레이어들 주변의 엔티티 중 화면에 필요한 값만 담고, 아이템 상자는 각자 자기 것만 받아 전송량을 줄입니다(보통 7KB 안팎).
- 맵은 모두 같은 맵 파일(`world.json`)을 쓰기 때문에 전송하지 않습니다. 시드는 떨어지는 물건 같은 운에만 씁니다.
- 게임 규칙은 위에서 내려다본 2D 평면 좌표로 계산하고, 렌더러(`render/World3D.ts`)가 3D로 그립니다. 월드 좌표 32px = 3D 1칸입니다.
- 접속을 연결할 때만 PeerJS 공개 서버를 쓰고, 게임 데이터는 브라우저끼리 직접 주고받습니다.

**알려진 제약**
- 참가자는 방장과 주고받는 시간만큼 조작이 늦게 반영됩니다(클라이언트 예측 없음).
- 회사망처럼 방화벽이 엄격한 네트워크에서는 P2P 연결이 안 될 수 있습니다(중계 서버 TURN 미사용).
- 방장이 나가면 게임이 끝납니다. (방장 탭이 뒤로 가거나 최소화돼도 게임은 계속 진행됩니다)

### 화면 구조

```
┌ Phaser 화면 (투명) ─ HUD, 지도, 이름표, 데미지 숫자, 바닥 경고 표시
└ Three.js 화면 ───── 지형, 나무·바위, 캐릭터, 몬스터, 투사체, 아이템
```

- 두 캔버스는 같은 크기로 겹쳐 있습니다. Phaser 쪽은 카메라를 움직이지 않으므로 좌표가 곧 화면 좌표입니다.
- 글자를 캐릭터 머리 위에 띄울 때는 `World3D.toScreen()`(월드 → 화면), 마우스 조준은 `World3D.toWorld()`(화면 → 바닥)를 씁니다.
- 같은 모델(나무, 바위 등)은 인스턴싱으로 한 번에 그립니다. 캐릭터는 모델을 복제해서 애니메이션을 따로 돌립니다.

### 밸런스 조정

거의 모든 수치가 `src/game/data/` 폴더에 주제별로 모여 있습니다.

| 바꾸고 싶은 것 | 위치 (`src/game/data/`의 파일) |
|---|---|
| 직업별 시작 능력치 / 레벨당 자동 상승 | `classes.ts`: `CLASSES.*.attrs` / `attrGrowth` |
| 직업별 기본 HP·공격·MP 등 | `classes.ts`: `CLASSES.*.bonus` |
| 능력치 1당 효과 (공격력, HP, 치명, MP 등) | `stats.ts`: `ATTR_EFFECT` |
| 레벨당 배분 포인트 | `stats.ts`: `POINTS_PER_LEVEL` |
| 기본 공격 (속도, 사거리, 위력) | `classes.ts`: `CLASSES.*.attack` |
| 스킬 이름·MP·재사용·배우는 레벨 | `classes.ts`: `CLASSES.*.skills` |
| 스킬 세부 수치 (범위, 배율, 지속시간) | `classes.ts`: `SKILL` |
| 스킬을 배우는 레벨 | `classes.ts`: `SKILL_UNLOCKS` |
| 적 능력치·행동 방식 | `enemies.ts`: `ENEMIES` (`ai`: hop·melee·ranged·heavy·dash·frost·bomb) |
| 구역별 적 강화 배율 | `enemies.ts`: `ZONE_HP` · `ZONE_ATK` · `ZONE_DEF` (`zoneScale`) |
| 인원수에 따른 적 체력 | `enemies.ts`: `partyHpScale` |
| 중간보스 / 문지기 | `enemies.ts`: `ELITES` / `GATE_KEEPERS` (보상 배율은 `ELITE`) |
| 구역별 출현 몬스터 비율 · 벽의 바위 비율 | `src/game/level.ts`의 `ZONE_POOLS` · `ROCK_CHANCE` ※ |

| 장비 이름·수치·얻는 곳 / 등급 드랍 확률 / 전체 드랍량 | `items.ts`: `ITEM_LIST` / `gear.ts`: `RARITY`·`shop.ts`: `SHOP.rarityWeight`(중간보스) / `gear.ts`: `ITEM_DROP_MULT` |
| 경험치 곡선 | `stats.ts`: `xpForLevel` |
