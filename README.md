# ACT RPG

최대 4명이 함께 즐기는 웹 기반 **3D 협동 액션 RPG**입니다. 워크래프트3처럼 비스듬히 내려다보는 시점으로 플레이합니다.
설치 없이 브라우저에서 바로 플레이하고, **저장 기능이 없습니다**. 매 판 1레벨 맨몸으로 시작해서 한 번에 최종 보스까지 깨야 합니다.

**▶ 플레이:** https://vozzang.github.io/act-rpg/

## 게임 방법

1. 닉네임을 입력하고 **방 만들기**를 누르면 5자리 방 코드가 나옵니다.
   **초대 링크 복사**로 친구에게 링크를 보내면, 친구는 코드가 채워진 상태로 바로 참가할 수 있습니다.
   혼자 하려면 **혼자 하기**를 누르세요.
2. 각자 직업을 고릅니다. 한 방에서 같은 직업은 한 명만 고를 수 있습니다.
3. 방장이 **게임 시작**을 누르면 출발합니다. 맵은 매 판 새로 만들어집니다.
4. 4개 구역을 지나 오른쪽 끝 보스 방의 **흑룡**을 쓰러뜨리면 승리합니다.

### 협동 규칙

- **경험치는 공유됩니다.** 적을 처치하면 살아 있는 파티원 모두가 같은 경험치를 받습니다.
- **카메라는 각자 따로 움직입니다.** 미니맵, 전체 지도(Tab), 화면 가장자리 화살표로 동료 위치를 확인하세요.
- **쓰러진 동료 곁에 2초간 서 있으면 부활**시킬 수 있습니다. 마법사의 치유의 빛으로도 바로 일으킬 수 있습니다.
- **새 구역에 들어서면** 쓰러진 동료는 맨 앞 동료 곁에서 부활하고, 모두의 HP가 25%, MP가 50% 회복됩니다.
- **모두 쓰러지면 전멸**입니다. 처음부터 다시 시작해야 합니다.
- 참가 인원이 많을수록 적 체력이 늘어납니다(1명 늘 때마다 +60%).

## 조작

키보드·마우스와 게임패드 모두 됩니다. 마지막으로 만진 장치에 맞춰 화면의 버튼 안내가 자동으로 바뀝니다.

### 키보드 + 마우스

| 동작 | 키 |
|---|---|
| 이동 | WASD 또는 방향키 (방향키로 움직이면 이동 방향으로 공격) |
| 조준 | 마우스 커서 방향 |
| 기본 공격 (누르고 있으면 연속) | 좌클릭 · Z |
| 스킬 1~4 | 숫자키 1~4 (우클릭·X·Space = 1번) |
| 아이템 줍기 · 상점 열기 | E |
| 상자 칸 사용 (음식 먹기 · 장비 내려놓기) | 5·6·7·8·9·0 또는 칸 클릭 |
| 음식 먹기 (HP / MP) | Q / R |
| 능력치 배분 | Shift+1~4 또는 화면 버튼 클릭 |
| 캐릭터 메뉴 | I |
| 전체 지도 | Tab(누르고 있기) · M(켜고 끄기) |

### 게임패드 (Xbox 이름, 괄호는 PlayStation)

| 버튼 | 동작 |
|---|---|
| 왼쪽 스틱 | 이동 |
| 오른쪽 스틱 | 조준. **안 쓰면 자동 조준** (이동 방향 앞쪽의 가장 가까운 적) |
| **X (□)** 누르고 있기 | 기본 공격 |
| **A (✕) · B (○) · Y (△)** | 스킬 1 · 2 · 3 |
| **RT (R2)** | 스킬 4 (최종 스킬) |
| **LB (L1) / RB (R1)** | HP 음식 / MP 음식 먹기 |
| **LT (L2)** | 줍기 · 상점 열기 |
| **Menu (Options)** | 캐릭터 메뉴: 능력치 배분, 아이템 상자 (방향패드로 고르고 A 실행, B 닫기) |
| **View (Share)** | 전체 지도 |

- 상점 창과 캐릭터 메뉴는 방향패드로 고르고 **A**로 실행, **B**로 닫습니다.
- 메뉴가 열려 있어도 게임은 멈추지 않습니다(온라인). 대신 **왼쪽 스틱 이동과 음식 먹기는 그대로** 되고, 공격·스킬만 막힙니다.

## 직업

직업마다 **체형(실루엣)이 달라서** 4명이 섞여 있어도 한눈에 구분됩니다.

| 직업 | 종족 | 주 능력치 | 기본 공격 | 특징 |
|---|---|---|---|---|
| **검사** | 휴먼 | 힘 | 빠른 근접 베기 | 균형 잡힌 능력치. 돌진으로 파고들어 싸운다. |
| **수호자** | 드워프 | 힘 | 느리지만 강한 도끼질, 강한 넉백 | HP와 방어가 높다. **적이 우선적으로 노린다.** |
| **궁수** | 엘프 | 민첩 | 포물선을 그리며 날아가는 화살 | 사거리가 가장 길고 치명타 확률이 높다. |
| **마법사** | 노움 | 지능 | 터지면서 범위 피해를 주는 마법 구체 | 파티 회복과 강력한 광역 마법을 쓴다. |

## 능력치

능력치는 **힘·민첩·지능·체력** 4가지입니다.

| 능력치 | 효과 |
|---|---|
| **힘** | 검사·수호자의 공격력, 방어 |
| **민첩** | 궁수의 공격력, 치명타 확률, 공격 속도 |
| **지능** | 마법사의 공격력, 최대 MP, MP 회복 속도, 스킬 재사용 가속, 회복 스킬 효과 |
| **체력** | 최대 HP, 방어 |

- 공격력은 **직업의 주 능력치**에서 나옵니다. 다른 능력치도 각자 쓸모가 있습니다. 예를 들어 마법사가 체력을 올리면 덜 죽고, 검사가 민첩을 올리면 더 빨리 벱니다.
- **레벨업할 때마다** 직업에 맞게 능력치가 자동으로 오르고, **포인트 3을 받아 원하는 곳에 직접 배분**할 수 있습니다.
- 레벨업하면 HP와 MP가 30%씩 회복됩니다.
- 화면 왼쪽 아래 정보창에서 현재 능력치(주 능력치는 ★)와 공격·방어·치명·공격 속도·스킬 가속을 볼 수 있습니다.

## MP와 스킬

### MP

- 모든 스킬은 MP를 씁니다. **위력이 큰 스킬일수록 MP가 많이 듭니다.**
- MP는 시간이 지나면 차오르고, 지능이 높을수록 최대치와 회복 속도가 늘어납니다.
- 레벨업할 때(30%), 새 구역에 들어갈 때(50%), MP 회복 음식을 먹을 때(50%) 회복됩니다.

### 스킬

직업마다 스킬이 4개입니다. 1레벨에는 하나만 쓸 수 있고, **Lv 4 · 7에 하나씩, Lv 10에 최종 스킬**을 배웁니다.
화면 아래 가운데 스킬 바에서 재사용 대기시간과 필요 MP를 볼 수 있고, 마우스를 올리면 설명이 나옵니다.

## 장비와 아이템 상자

- 화면 아래 스킬 바 밑에 **아이템 상자 6칸**이 있습니다. 장비 하나, 또는 같은 종류 음식 한 묶음이 한 칸을 차지합니다.
- **상자에 든 장비는 종류와 상관없이 모두 능력치에 더해집니다.** 무기를 두 개 들면 두 개 다 적용됩니다.
  칸이 6개뿐이라 장비를 더 들지, 회복 음식을 더 들지 골라야 합니다.
- 적이 떨어뜨린 장비 위에 서서 **E**를 누르면 빈 칸에 들어갑니다. 상자가 가득 차면 주울 수 없습니다.
- **상자 칸을 클릭하거나 단축키 5·6·7·8·9·0**(1~6번째 칸)을 누르면 음식은 하나 먹고, 장비는 발밑에 내려놓습니다(능력치에서 빠짐). 마우스를 올리면 설명이 나옵니다.
  상점 창이 열려 있을 때는 숫자키가 구매에 쓰입니다.
- 장비 칸은 등급 색으로, 음식 칸은 HP 빨강·MP 파랑과 개수(×3)로 표시됩니다.

| 칸 | 기본 수치 | 추가 수치 |
|---|---|---|
| 무기 | 공격력 | 희귀 이상: 힘·민첩·지능 중 하나 / 전설: 치명 +5% |
| 방어구 | 방어, 체력 | |
| 장신구 | 치명타 확률, 능력치 하나 | 영웅 이상: 능력치 하나 더 |

| 등급 | 색 | 수치 배율 | 드랍 확률 |
|---|---|---|---|
| 일반 | 흰색 | ×1.0 | 60% |
| 희귀 | 파랑 | ×1.6 | 28% |
| 영웅 | 보라 | ×2.4 | 10% |
| 전설 | 주황 | ×3.6 | 2% |

- **깊은 구역에서 나온 장비일수록 기본 수치가 높습니다.** 이름 앞의 재질(낡은 → 강철 → 미스릴 → 용비늘)로 구분할 수 있습니다.
- 적은 가끔 **회복 음식**도 떨어뜨립니다. 닿으면 주워서, 필요하면 바로 먹고 가득 차 있으면 아이템 상자에 넣습니다.
  - **빨간 빛** 위의 햄·사과: HP 35% 회복 — 상자에서 꺼내 먹기 **Q**
  - **파란 빛** 위의 포도·포도주: MP 50% 회복 — 상자에서 꺼내 먹기 **R**
  - HP 음식, MP 음식은 **각각 최대 5개**까지 들 수 있습니다(각각 상자 한 칸).
- 처음에는 상자에 HP·MP 음식이 하나씩 들어 있습니다.

## 돈과 상점

- 몬스터를 쓰러뜨리면 **항상 금화**가 떨어집니다. 깊은 구역의 적, 정예 오크일수록 많이 줍니다.
- 금화는 가까이 가면 저절로 끌려옵니다. **누가 줍든 파티 전원이 같은 만큼 받습니다**(경험치처럼).
- **출발 지점과 2·3·4구역 입구**에 상점이 있습니다. 붉은 천막 가판대와 상인이 있고, 지도에는 노란 점으로 표시됩니다.
- 상인 곁에서 **E**를 누르면 상점 창이 열립니다. **숫자키 1~5** 또는 클릭으로 사고, E·Esc를 누르거나 멀어지면 닫힙니다.

| 진열 | 값 | 비고 |
|---|---|---|
| HP 회복 음식 | 20 G | 아이템 상자에 들어간다 (Q로 먹기, 최대 5개) |
| MP 회복 음식 | 20 G | 아이템 상자에 들어간다 (R로 먹기, 최대 5개) |
| 장비 3개 | 등급·구역에 따라 | 상점마다 무작위. 필드보다 좋은 등급이 잘 나온다. **하나뿐이라 누가 사면 품절** |

- 장비 값: 일반 25 · 희귀 55 · 영웅 110 · 전설 240 G (구역이 하나 깊어질 때마다 60%씩 비싸짐)
- 산 물건은 아이템 상자에 들어갑니다. 상자에 빈 칸이 없으면 살 수 없습니다.

## 스테이지와 적

| 구역 | 이름 | 주로 나오는 적 |
|---|---|---|
| 1 | 초록 숲 | 슬라임, 고블린 |
| 2 | 고블린 협곡 | 고블린, 슬라임, 해골 궁수 |
| 3 | 해골 묘지 | 고블린, 해골 궁수, 오크 전사 |
| 4 | 오크 요새 | 해골 궁수, 오크 전사, 고블린 |
| 보스 | 흑룡의 둥지 | 흑룡 |

- 길은 **지그재그**입니다. 구역마다 통로 3줄이 위아래로 쌓여 있고, 오른쪽 → 왼쪽 → 오른쪽으로 꺾어 지나갑니다.
  통로 사이는 숲·바위 벽이라 질러갈 수 없고, 구역이 바뀔 때마다 들어오는 줄이 위·아래로 번갈아 바뀝니다.
  (맵 모양은 매 판 조금씩 다르지만 이 구조는 같습니다. `src/game/level.ts`의 `LANES`, `ZONE_W` 등으로 조정)
- 각 구역 출구에는 정예 **오크 전사**가 지키고 있습니다. 깊은 구역의 적일수록 강합니다.
- **해골 궁수**는 거리를 벌리며 활을 쏘고, 장애물에 시야가 막히면 돌아서 다가옵니다.
- **오크 전사**는 몸이 빨갛게 깜빡인 뒤 크게 내려찍습니다. 깜빡일 때 피하세요.

### 중간보스

각 구역에서 길이 U자로 꺾이는 두 곳을 중간보스가 지킵니다. 몸집이 크고 발밑에 **금빛 고리**, 머리 위에 **이름과 체력바**가 있으며,
처음 마주치면 "⚔ ○○ 등장!" 배너가 뜹니다. 벽 너머(옆 통로)에 있을 때는 깨어나지 않습니다.

| 구역 | 첫 번째 꺾이는 곳 | 두 번째 꺾이는 곳 |
|---|---|---|
| 1 초록 숲 | 거대 슬라임 | 고블린 대장 |
| 2 고블린 협곡 | 고블린 대장 | 해골 저격수 (화살 3발 부채꼴) |
| 3 해골 묘지 | 해골 저격수 | 오크 광전사 |
| 4 오크 요새 | 오크 광전사 | 오크 족장 |

- 같은 구역의 정예 오크보다 강하고, **뒤 구역일수록 기본 능력치 자체가 높아지고 구역 보정까지 더해져** 점점 강해집니다.
- 넉백을 거의 받지 않고, 기절 시간도 절반입니다.
- 처치하면 경험치 6배, 돈 8배를 주고, **좋은 등급 장비 하나와 회복 음식을 반드시** 떨어뜨립니다.
- 능력치는 `src/game/data.ts`의 `ELITES`(중간보스별 HP·공격·방어)와 `ELITE`(보상 배율 등)에서 조정합니다.

### 최종 보스: 흑룡

| 패턴 | 설명 |
|---|---|
| 도약 | 날아올라 플레이어에게 내려찍고, 사방으로 충격파를 퍼뜨린다. 착지 지점에 빨간 경고가 뜬다. |
| 돌진 | 빨갛게 깜빡이며 힘을 모은 뒤 빠르게 돌진한다. |
| 화염탄 | 플레이어 주변에 화염탄을 뱉는다. 떨어질 자리에 빨간 원이 깜빡인다. |
| 부하 소환 | 체력이 절반 이하로 떨어지면 더 빨라지고, 고블린을 불러낸다. |

## 개발

### 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 를 정적 호스팅에 올리면 된다
npm run typecheck  # 타입 검사
```

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 빌드해서 GitHub Pages에 자동 배포합니다.

**개발 서버 전용 바로 시작:** `http://localhost:5173/?autostart=elf&seed=1` 처럼 열면 로비를 건너뛰고 혼자 바로 시작합니다.
직업은 `swordsman`, `dwarf`, `elf`, `gnome` 중 하나입니다. 이때 브라우저 콘솔에서 `sim`으로 게임 상태를 살펴보고 바꿀 수 있습니다(예: `sim.players[0].hp = 9999`). 배포된 사이트에는 적용되지 않습니다.

### 기술 스택

- **Three.js**: 3D 월드 렌더링 (지형, 캐릭터 모델과 애니메이션, 조명·그림자)
- **Phaser 3**: HUD, 글자, 입력 (3D 화면 위에 투명하게 겹친 2D 화면)
- **TypeScript + Vite**: 개발 환경과 빌드
- **PeerJS (WebRTC)**: 브라우저끼리 P2P 통신. 별도 게임 서버 없음

### 폴더 구조

```
src/
  game/            게임 규칙 (Phaser와 무관한 순수 TS)
    data.ts        밸런스 데이터: 직업·능력치·스킬·적·장비·경험치   ← 수치 조정은 여기
    level.ts       시드 기반 맵 생성 (지그재그 통로, 숲·바위 벽, 구역, 상점, 보스 방, 몬스터 배치)
    physics.ts     충돌, 시야(격자 순회), 길찾기(BFS 거리 지도)
    sim.ts         게임 시뮬레이션 (방장 브라우저에서만 실행)
    types.ts       상태·입력·스냅샷 타입
  net/net.ts       PeerJS P2P 통신 (방 만들기 / 참가)
  render/          화면 (게임 규칙은 모르고 스냅샷을 그리기만 한다)
    GameScene.ts   메인 루프, 입력, 네트워크 동기화, 캐릭터 머리 위 표시
    World3D.ts     3D 월드: 모델 불러오기, 지형, 캐릭터·애니메이션, 투사체, 카메라, 화면↔월드 좌표 변환
    Hud.ts         파티 패널, 내 정보창, 능력치 버튼, 스킬 바, 보스 체력
    MapView.ts     미니맵, 전체 지도
    Effects.ts     데미지 숫자, 배너, 공격 범위, 폭발, 승리·전멸 화면
    ui.ts          글꼴, 글자 만들기
  main.ts          로비: 방 만들기, 참가, 직업 선택, 게임 시작·종료
  session.ts       로비와 게임 화면이 주고받는 정보
```

### 온라인 구조 (호스트 권한 방식)

```
참가자 브라우저 ── 입력(이동·조준·공격·스킬) ──▶ 방장 브라우저 (Sim 실행)
참가자 브라우저 ◀── 스냅샷(초당 20회) ──────── 방장 브라우저
```

- 방장 브라우저가 게임을 초당 60회 계산하고, 초당 20회 상태를 참가자에게 보냅니다.
- 참가자는 입력만 보내고, 받은 상태를 부드럽게 이어서(보간) 그립니다.
- 스냅샷에는 플레이어들 주변의 엔티티만 담아 전송량을 줄입니다.
- 맵은 시작할 때 받은 시드로 각자 똑같이 만들기 때문에 전송하지 않습니다.
- 게임 규칙은 위에서 내려다본 2D 평면 좌표로 계산하고, 렌더러(`render/World3D.ts`)가 3D로 그립니다. 월드 좌표 32px = 3D 1칸입니다.
- 접속을 연결할 때만 PeerJS 공개 서버를 쓰고, 게임 데이터는 브라우저끼리 직접 주고받습니다.

**알려진 제약**
- 참가자는 방장과 주고받는 시간만큼 조작이 늦게 반영됩니다(클라이언트 예측 없음).
- 회사망처럼 방화벽이 엄격한 네트워크에서는 P2P 연결이 안 될 수 있습니다(중계 서버 TURN 미사용).
- 방장이 나가면 게임이 끝납니다.

### 화면 구조

```
┌ Phaser 화면 (투명) ─ HUD, 지도, 이름표, 데미지 숫자, 바닥 경고 표시
└ Three.js 화면 ───── 지형, 나무·바위, 캐릭터, 몬스터, 투사체, 아이템
```

- 두 캔버스는 같은 크기로 겹쳐 있습니다. Phaser 쪽은 카메라를 움직이지 않으므로 좌표가 곧 화면 좌표입니다.
- 글자를 캐릭터 머리 위에 띄울 때는 `World3D.toScreen()`(월드 → 화면), 마우스 조준은 `World3D.toWorld()`(화면 → 바닥)를 씁니다.
- 같은 모델(나무, 바위 등)은 인스턴싱으로 한 번에 그립니다. 캐릭터는 모델을 복제해서 애니메이션을 따로 돌립니다.

### 밸런스 조정

거의 모든 수치가 `src/game/data.ts`에 모여 있습니다.

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 직업별 시작 능력치 / 레벨당 자동 상승 | `CLASSES.*.attrs` / `attrGrowth` |
| 직업별 기본 HP·공격·MP 등 | `CLASSES.*.bonus` |
| 능력치 1당 효과 (공격력, HP, 치명, MP 등) | `ATTR_EFFECT` |
| 레벨당 배분 포인트 | `POINTS_PER_LEVEL` |
| 기본 공격 (속도, 사거리, 위력) | `CLASSES.*.attack` |
| 스킬 이름·MP·재사용·배우는 레벨 | `CLASSES.*.skills` |
| 스킬 세부 수치 (범위, 배율, 지속시간) | `SKILL` |
| 스킬을 배우는 레벨 | `SKILL_UNLOCKS` |
| 적 능력치 / 구역별 강화 / 인원수 보정 | `ENEMIES` / `zoneScale` / `partyHpScale` |
| 장비 등급 확률·배율 | `RARITY` |
| 경험치 곡선 | `xpForLevel` |
